# JMB Creations Studio

Create a polished, responsive e-commerce website mockup for a family-run creative business named “JMB 2 Creations.”

BUSINESS OVERVIEW

JMB 2 Creations is a family-run creative shop selling a wide variety of handmade and 3D-printed products. Their catalog includes:

- 3D-printed bag charms

- Straw toppers

- Keychains and small trinkets

- Mini-figure shelves and display stands

- Cosplay props and decorative cosplay swords

- Sports-themed items

- Personalized gifts

- Custom-colored products

- Seasonal products

- Collectibles

- Other creative 3D-printed items

The business currently sells through facebook marketplace, social media, and flea/farmers markets but wants its own online store. Customers must be able to place orders for shipping or choose local in-person pickup.

This first version is a client-facing website mockup, but the structure should be designed so it can later become a fully operational e-commerce website without needing a complete redesign.

BRAND DIRECTION

Use the uploaded JMB 2 Creations logo as the main visual reference. It's file name is under logo.png

Color palette:

- Soft blush pink: #F9C9D0

- Pastel pink: #FBB6C3

- Lavender: #8C83CA

- Deep periwinkle blue: #585AAA

- Mauve purple: #AA709F

- White: #FFFFFF

- Very dark purple for readable text: #29233F

The design should feel:

- Playful

- Creative

- Colorful

- Family-friendly

- Collectible-inspired

- Handmade

- Welcoming

- Modern and trustworthy

Avoid making the website look overly childish, cluttered, or like a generic Etsy template.

Use large rounded cards, soft shadows, pastel gradients, rounded buttons, playful borders, and subtle decorative shapes. Include small floating charm, sparkle, star, cube, or filament-inspired illustrations throughout the site.

Animations should be gentle and polished. Examples include slowly floating trinkets, soft button movement, subtle card lifts, and smooth page transitions. Do not allow animations to interfere with shopping or reading.

TYPOGRAPHY

Use a bold rounded display font such as Fredoka for headings.

Use a clean, highly readable font such as Nunito Sans or Inter for body text, product information, checkout forms, and dashboard content.

LOGO USAGE

Use a tightly cropped transparent version of the JMB logo in the navigation bar.

The full square logo can be used in the homepage hero, footer, social sharing preview, and favicon assets.

Do not redesign or alter the logo.

TECHNICAL DIRECTION

For this initial version:

- Build a complete responsive front-end mockup

- Use reusable components

- Use mock product and order data

- Use local state for cart interactions

- Do not process real payments

- Do not send real emails

- Do not require a live database

- Make all major buttons and navigation paths functional within the mockup

Structure the project so it can later connect to:

- Supabase for authentication, database, product records, orders, customer accounts, and file storage

- Stripe for secure online payments

- Email notifications for order confirmations, status changes, shipping, and pickup readiness

- Cloud storage for product and customer reference images

Do not connect these production services during the mockup phase unless specifically requested.

RESPONSIVE DESIGN

The website must look polished on:

- Desktop

- Laptop

- Tablet

- Mobile phones

On mobile:

- Keep checkout controls easy to tap

- Use a sticky add-to-cart button on product pages

- Use a clean filter drawer on the shop page

- Keep the cart and account icons visible

- Ensure the admin dashboard remains usable

ACCESSIBILITY AND QUALITY

- Maintain strong text contrast

- Include visible focus states

- Use descriptive form labels

- Include image alt-text placeholders

- Avoid text over busy backgrounds

- Use smooth but restrained animation

- Optimize the design for fast loading

- Include empty, loading, error, and success states

- Add clear validation messages to forms

The final result should feel like a cheerful digital maker studio filled with colorful creations, while remaining organized, easy to shop, and ready to grow into a full e-commerce platform.
